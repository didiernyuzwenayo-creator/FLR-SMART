# FLR SMART — Field Officer Learning Edition

FLR SMART is a mobile-friendly learning workspace for Field Officers supporting Forest Landscape Restoration (FLR).

## Learning pathway

The Learning Center is the primary focus of this version. It contains structured lessons on:

1. Forest Landscape Restoration fundamentals
2. FLR principles and landscape thinking
3. Agroforestry and trees on farms
4. Soil and water conservation
5. Tree nursery and seedling quality
6. Species selection and site matching
7. Planting preparation, planting and aftercare
8. Farmer training and field facilitation
9. Planting, survival and impact monitoring
10. Field data quality, safeguarding and reporting

Lessons include learning objectives, key concepts, field applications, further reading and a knowledge check.

## Evidence and sources

The learning material is based on publicly available references from:
- One Acre Fund / Tubura Rwanda programme information and training resources.
- Rwanda Forestry Authority and the National Agroforestry Strategy.
- Rwanda Water Resources Board's Water Portal.
- Rwanda's Forest Landscape Restoration Opportunity Assessment.
- Public One Acre Fund / Laterite evaluation material on agroforestry in Rwanda.

These public references are not internal Tubura FLR standard operating procedures. Internal SOPs, approved species lists, package specifications, spacing standards, monitoring definitions and supervisor instructions must take precedence for operational decisions.

## Other Field Officer tools

The prototype retains farmer records, tree distribution, planting survey, daily field reports and a field calculator. These tools currently save data in the browser's local storage on the current device only.

## Important limitations

- Dashboard demo figures and preloaded demo farmer records have been removed.
- No live Tubura operational database is connected.
- Browser-local records are not shared, backed up or synchronized across users or devices.
- Do not enter personal farmer data or confidential project information unless authorized and an approved secure system is available.
- The website is a learning and development tool, not an officially approved Tubura system.
